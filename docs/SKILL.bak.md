# 思想随笔写作

## 风格定义

以克制承载力量、以朴素书写崇高、以"我们"发声的中文思想随笔风格。目标是写出一个人独坐时真正在想的东西——不是宣言，不是说教，不是命题作文的参考答案。

不呐喊、不煽情、不说教。用最简单的词语（如："一口饭""一束光""一条路"）托住最沉重的话题（如：生存、尊严、文明的存续）。说服力不来自音量的升高，而来自对困境的彻底承认——承认之后仍然选择相信，这份相信才真正坚硬。

论证不是线性的 A→B→C，而是螺旋的、回环的：先把一个念头拉到地面，再用复杂性和反例一层层剥去天真，最后在几乎放弃确定性的地方，找到一个更结实的支点。

声音来自"我们"——作者和读者并肩思考，面对相同的问题。不是居高临下的启蒙或说教，而是平等位置的确认与感同身受。不是说不能用"你"，只是"你"应当让读者带入第一人称去感受，而非进入第二人称被作者说教、指导。

## 创作铁律

以下五条不可违反：

**一、禁止套用参考源中的任何原句或句式结构。** 包括直接搬运、微调搬运（如替换一个动词仍是抄袭）、复用参考源中的结尾句式。结尾句尤其危险——那些短促有力的收束句最具记忆黏性。写完结尾后，逐词对照参考源确认句式骨架是否独立。如果发现句式骨架相似，请重新构思句子结构，确保独立性。

**二、写作素材必须来自你的经历、阅读积累或后期研究的具体内容，而技巧与风格应模仿参考资料。** 参考源的内容教写法，不提供素材。例子必须来自你亲历的、你读过的、你观察到的具体内容。参考源不是素材库。

**三、不要写议论文，不要写命题作文，不要答题。** 思想随笔是探索与观察，不是论证。如果你的文章呈现出"提出命题 → 数据佐证 → 分析原因 → 给出结论"的结构，你写的是一篇议论文，不是思想随笔。读者读完应该感到被触及，而不是被说服——你不需要给出标准答案。命题词在全文中自然出现，但不成为段落组织的脚手架。

**四、结构模板用于理解逻辑，不是操作手册。** "立→破→困→转→再立"描述了一种论证逻辑。如果你写完发现每段恰好对应一步，且读者能清晰辨认"这是破""这是转"——重写。好的螺旋让读者感到层层深入，但无法定位具体步骤。

**五、写作前必须完整阅读六个参考源的 `analysis.md` 文件和优秀文章案例。** 确保理解所有技法内容，每个参考源提供不同的技法维度，缺一不可。

## 任务流程

（不用创建 TODO 列表）严格按照顺序执行，不可跳步：

### 1. 深究命题

1. 接到任务后，必须先尝试向用户问清楚细节，如字数、主题等，若用户未提供足够信息、太宽泛、模糊，应当进一步询问。
2. 然后用 web 搜索等方式了解相关背景、不同观点、具体案例。这一步的目标不是收集素材直接塞进文章，而是确保你对命题有超出常识的、全面的理解。搜索时注意记录自己真正被触动的事实或细节。
3. 在了解完命题后，写一段总结，明确你对命题的理解和你打算从哪个角度切入，把这个总结发给用户确认并询问。只有在用户确认你对命题的理解正确，才进入下一步，否则必须与用户讨论并校正后，再次要求确认。

如果用户提供的命题有明确的倾向或预设，尝试找到反面观点并深入理解它们。不要急于形成自己的观点，先把所有相关信息吃透。必须在写作前对命题有一个清晰、深入的理解，否则继续探索或者询问用户。

### 2. 读取参考

读取六份 `analysis.md`，提取与当前命题相关的技法，然后按需读取对应目录下的其余参考文件。调用 Python 脚本，获取已有的优秀文章案例并学习，方法：`py essence.py [--limit <n>]`——不要记句子与情节，不要抄袭，记"它用了什么结构、技巧、风格"、"它在哪个位置做了什么事"。

**`essence.py` 使用说明：**
- `py essence.py` — 默认输出前 5 篇优秀文章（评分 > 75），含原文、扣分理由、亮点
- `py essence.py --limit 3` — 仅输出前 3 篇
- `py essence.py --limit 0` — 输出全部

### 3. 写作 

全文中文，除专有名词外禁用英文。严格按照写作流程与要求进行，过程中禁止统计字数。写完后，必须将文章保存在 `./output` 目录下，命名为 `{话题关键概括}.txt` 文件（少于 16 个字符，注意名称中不能包含特殊字符），纯文本格式，禁止 Markdown 语法，首行为标题（前加井号：`# 标题`），每段之间空一行。

### 4. 统计总结

用命令行调用 Python 统计准确字数，禁止手动估算。例：`py count.py output/<filename>.txt`。如果字数过多或过少（~10%），返回写作步骤调整内容后重新统计，直到字数达标。

### 5. 深度复盘

1. 内容的来源：没有来自参考源的内容吧？
2. 比喻/意象的原创性：在参考源里不存在相似物吧？
3. 声音的独立性：读者读完能感觉到你的声音吗？没有居高临下说教议论吧？
4. 结构的自然性：是从命题内部生长出来的吗？不像填好的模板或命题作文吧？
5. 流程合规：没有任何违反创作铁律或核心原则的内容吧？是否先做了 web 搜索深究命题？是否读完了六份 `analysis.md`和优秀文章案例？是否用命令行统计了字数而非手动估算？
6. 金句部署：破的尾部 / 困的深处 / 再立之前——适当情况下，三个位置有可独立引用的悖论式金句吗？如果没有，从论证张力最紧处自然生成，不要硬造。

如果对于上述问题存在任一答案为"否"——回去补足缺失步骤、修复问题或者重写，然后再检查，直到所有项都为"是"。

## 核心原则

### 1. 重力修辞

力量来自所述之事本身的重量。全文很少出现感叹号。让句子自己承载情感，而非靠符号来声明。

> ❌ "我们必须坚持希望！未来一定会更好！"
> ✅ "只要还有人走，路就不会断。"

### 2. 朴素崇高

大词必须落地，不讲空话大道理。用日常单位替代抽象概念，例如："一口饭"替生存权，"一个家"替归属感，"一束光"替希望。

> "文明的存续，不刻在帝王的墓碑上。它只藏在每一个普通人，不肯低头的脊梁里。"

### 3. 螺旋论证

不写线性论证（A→B→C）。按 "立→破→困→转→再立" 组织：陈述念头 → 承认其艰难 → 直面当代死结 → 引入历史反例打破必然性幻觉 → 在更坚实的地基上重建信念。每一次"破"剥去一层天真，最终的"立"更硬、更真。

如果你的文章结构可以用一句话概括为"我认为 X，因为 A、B、C，所以我们应该 Y"——你写的是议论文，不是思想随笔。螺旋的每一步必须从命题内部自然生长，不能是论证链条上可定位的环节。

### 4. 祛魅理想

守护理想，但不神化它。彻底承认黑暗——然后仍然选择光。这不是伪装成乐观的悲观，而是被拆解之后仍然活下来的乐观。不是天真的理想主义，也不是犬儒的厌世，而是对理想的清醒坚持。

> "我们心怀理想，但不迷信未来。我们看清黑暗，但不与黑暗同流。"

### 5. 共同体之声

用"我们"，不用"你"。并肩面对相同的困惑，发出相同的追问。权威来自共享的脆弱，而非宣告的正确。我们都在这个困境里，没人能置身事外。不是"你应该""人们必须"，而是"我们都在……""我们都会……"——把读者拉进来，而非推到一边。

### 6. 降维锚定

每一个抽象论断后，立刻接一个身体可感的锚点。例如：说完"历史不是写好的剧本"，立刻接上具体的历史时刻；说完"文明的存续只是侥幸（来自普通人）"，立刻落到"伸出的手、说的不、不肯熄灭的光"。

### 7. 悖论张力

保留矛盾，不要急于化解。"希望是残酷的""保护者也必将是施害者"——这些是对真实的承认，真实不会自动化解为舒适。

### 8. 排比功能化

每组排比必须承担独立的论证功能：
- 肯定式：构建愿景（如"没有人再……没有人再……没有人再……"）
- 内省式：拆解复杂性（如"人会比较，会嫉妒，会想要……"）
- 历史反证式：打破必然性（如"一千年前……八十年前……五十年前……三十年前……"）

绝不为装饰而刻意排比。

### 9. 隐喻承载

隐喻不是装饰品，它承载论证的骨架。选定一个核心隐喻，让它从头到尾承担结构重量，不堆砌、不漂移。进阶：代际句式镜像——不同世代使用完全相同的句式，在文本层面建立传承的证明。

如果文章有标题，标题中的意象必须在正文中出现并承担论证功能。标题用"浅水区与深水区"但正文从不涉水，这是错误的——意象不是标签，是文章的血肉。

### 10. 细节锚定

每个抽象判断必须绑定一个具体的感官场景，用视觉、触觉、动作等细节展示特征，用具体场景与行动，而非简单地用形容词概括。

❌ "父亲是一个勤劳的人。"
✅ "父亲天不亮就起床，大雪里深一脚浅一脚走五里路去上班。"

### 11. 不急于下结论

不要替读者完成思考。在提出矛盾之后，允许它悬置。四种身份并置，不加裁决。真相不在作者的判断里，而在读者自己拼凑的过程中。把下结论的权利和重量交还给读者。

## 素材来源

"写什么"必须来自你自己的储备。每一个抽象论断需要一个具体的锚点，这个锚点不能从参考源借。它必须来自：

- 你亲历或见证过的具体时刻
- 你独立了解的历史事件或社会现象
- 你对命题的独立思考——不要套用参考源的结论

## 金句

每篇文章在"破的尾部""困的深处""再立之前"三个位置各适当部署一句高密度悖论陈述。

特征：单句、可独立引用、去掉上下文仍有完整重量。不是装饰——它所在的位置如果换成平实陈述，论证的力度就会减弱。一篇文章一到三句即可。

| 落点 | 功能 | 示例 |
|------|------|------|
| 破的尾部 | 用一个悖论收束"承认困境"的段落 | "欲望不可耻，它只是太轻了。" |
| 困的深处 | 在矛盾最紧处，一句话点穿本质 | "我们以为自己不会失去，结果什么都不曾真正拥有。" |
| 再立之前 | 在重建信念前夕，用悖论清理地基 | "不是所有的等待都有结果。但有些事，不等就永远不会发生。" |

如果你发现自己在刻意制造金句而非让金句从论证中自然产生——删掉，用平实陈述替代，禁止刻意硬造。

## 结构参考

仅供理解论证逻辑，非操作手册，你不必严格地按照以下结构划分段落：

```
§1–2：立——陈述念头。用朴素词语，不做宏大叙事。
§3–4：破——承认困境。用"我们不得不承认"作为转折。
§5–6：困——呈现当代死结。点出悖论，用"似乎"保留不确定性。
§7–8：转——引入反证。加速式时间排布（千年→百年→十年），"没有人能想到"为叠句。
§9–11：再立——重建支点。不是"因此理想必胜"，是"因此选择仍在我们手中"。以轻盈收束沉重。
```

如果你写完发现每段恰好对应一步，且易于辨认——重写。真正好的螺旋让读者感到层层深入，但无法定位具体步骤，不要写成议论文。

## 常见错误

- **过早和解**：误：矛盾未充分展开即给答案。正：让"困"充分呼吸。
- **隐喻通胀**：误：核心隐喻出现三次以上。正：选一个，绕它运行。
- **假克制**：误：低调是风格标签而非内化立场。正：克制来自对困境的真正面对。
- **僭越"我们"**：误：未分担的苦难却说"我们"。
- **形容词替代**：用"他很善良"替代"他把最后一块饼掰成两半分给同路人"——前者偷懒，后者写作。
- **答题结构**：误：文章呈现"命题→数据→分析→结论"的线性链条。正：思想随笔让读者感到探索与思考，不是被说服。
- **论文式引用**：误："一份 2025 年的调查显示""超过 X% 的人认为"——如果必须用事实，把它消化为生活中的个人观察或具体场景，禁止直接引用外部权威。
- **收束太干净**：误：最后一句话回答了命题或给出了出路。正：结尾应该留下未上弦的弓——让矛盾存在，而不是被完美解决。

## 危险信号

- 靠感叹号证明情感强度 → 句子本身不够强，重写
- 堆叠隐喻（例：光、火、种子、春天等）→ 选一个
- 读起来在刻意"鼓舞人心" → 拆掉升调，让读者自己找到希望
- 告诉读者该感受什么 → 换成你观察到的事实
- 替读者下结论、给解决方法 → 把矛盾留住
- 例子来自参考源 → 停笔，翻自己的记忆和阅读
- 能在参考源找到相似句 → 套用了，重写
- 结尾句与参考源只差一两词 → 句式复用，从零重建
- 没读完全部六份 analysis.md 就开始写 → 停笔，读完再来
- 删标题后读者既猜不出方向也感觉不到主题 → 太隐晦，让命题词在关键位置自然浮现几次
- 全文无可独立引用的句子 → 缺金句，尝试在破/困/再立前三个位置适当补句
- 出现"据调查""数据显示"等外部引用 → 消化为个人观察或具体场景
- 用"我们不得不承认""困境就在于"组织段落 → 换掉说教脚手架，让事实本身说话
- 读完发现文章在证明一个论点 → 拆掉论证结构，回归探索与观察
