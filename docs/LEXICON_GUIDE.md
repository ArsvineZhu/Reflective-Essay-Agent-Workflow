# 词库系统使用说明

## 概述

recommend 工具内置完整的词库系统，用于主题语义匹配、技法识别和问题检测。词库系统采用模块化设计，包含 8 个 JSON 词库和 1 个同义词词林文本文件。

## 词库文件结构

```
.opencode/lexicon/
├── cilin.txt                   # 哈工大同义词词林扩展版（原始语料）
├── stop-words.json             # 停用词库
├── topic-lexicon.json          # 主题词库（15个分类）
├── technique-lexicon.json      # 技法词库（12种写作技法）
├── concept-mapping.json        # 概念映射词库（19个核心概念）
├── issue-patterns.json         # 问题模式库
├── structure-patterns.json     # 结构模式库
├── reader-styles.json          # 读者风格定义
└── personas.json               # 代理人格设定
```

注意：`.bak` 后缀的文件为自动备份，系统运行时自动生成，可以忽略。

## 词库详解

### 1. 停用词库 (stop-words.json)

**用途**：过滤无实际语义的常用词，提升关键词提取质量。

**包含分类**：
- **连词介词**：的、了、在、是、有、和、就等
- **正式表达**：特此、为此、据此、因此、因而等
- **文章相关**：文章、全文、正文、标题、内容等

**词量**：约 150 个停用词

| 技法 | 核心特征 | 关键词示例 |

| **隐喻承载** | 核心意象贯穿全文 | 像、如、似、仿佛、犹如、宛如 |
| **降维锚定** | 宏大概念落地日常 | 一口饭、一杯水、一盏灯、一条路 |
| **功能排比** | 排比句式服务论证 | 没有人、不是...不是、不必...不必 |
| **克制抒情** | 情感含蓄节制 | 平静、沉默、淡然、坦然、克制 |
| **开放性结尾** | 结尾留思考空间 | 也许、或许、可能、谁知道呢 |

| **碎片化散文** | 段小蒙太奇拼接 | 片段、镜头、画面、切换、闪回 |

**包含特征**：每个技法都有关键词、句式指示器、权重配置。

### 5. 问题模式库 (issue-patterns.json)

**用途**：识别文章中的常见扣分点和可改进方向，供 recommend 工具在输出中提示。

| 类别 | 模式 | 严重度 |
|------|------|--------|
| **结构问题** | 说教框架、议论文结构、转折过多、结尾太干净 | medium/high |
| **文风问题** | 感叹号滥用、居高临下、鸡汤励志、学术化引用 | high/medium |
| **内容问题** | 概念堆砌、隐喻过多、金句感过强、举例通用化 | medium/low |
| **语言问题** | 翻译腔、陈词滥调、模糊表述、副词滥用 | medium/low |
| **原创性问题** | 网络流行语、引用过度 | medium |

---

### 6. 结构模式库 (structure-patterns.json)

**用途**：识别文章的整体结构类型（螺旋、线性、碎片等），支持通过同义词词林扩展识别词。

由 `recommend` 工具的 `updateLexicon` 参数自动维护扩展词，种子词来自词库内置定义。

---

### 7. 读者风格库 (reader-styles.json)

**用途**：存储 16 种读者风格的定义，通过 `load-reader-style` 工具按 ID 加载。

**风格列表**：感性读者、怀旧型读者、共情型读者、怀疑论者、哲学型读者、实用主义者、审美型读者、翻译耳读者、节奏型读者、普通路人、亲历者型、文化比较者、锐度审查者、套路督察官、权力审视者、庸俗读者、完整性审查者

---

### 8. 人设库 (personas.json)

**用途**：存储代理人格设定，通过 `load-persona` 工具按代理 ID 加载，仅非工作交流时使用。

---

### 9. 哈工大同义词词林 (cilin.txt)

**用途**：作为词库扩展的原始语料源。`recommend` 工具在 `updateLexicon=true` 时读取该文件，通过词林分组扩充各词库的同义词集合，提升匹配召回率。

**包含**：约 7 万词条，按语义层级分组。

## 匹配算法

### 召回率提升

通过概念映射词库，输入"愧疚"时会自动扩展匹配：
- **同义词**：愧疚、内疚、惭愧、羞愧
- **近义词**：亏欠、抱歉、过意不去
- **相关词**：罪恶感、自责、后悔、遗憾

召回率提升约 60%。

### 多样性优化

推荐结果自动打散同一分类的文章，避免推荐过多主题相似的文章。

## 参数

recommend 工具的词库相关参数：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `categories` | string[] | 可选 | 指定主题分类过滤。如：`["家庭与亲情", "互联网与文化"]` |
| `rebuildIndex` | boolean | false | 强制重建文章索引。词库更新后使用。 |
| `updateLexicon` | boolean | true | 使用哈工大同义词词林扩展版扩充词库后执行推荐。 |

**示例调用：**

```typescript
// 指定家庭与亲情分类，要求包含细节锚定技法
await tool.call("recommend", {
  topic: "愧疚教育",
  categories: ["家庭与亲情", "教育与成长"],
  techniques: ["细节锚定", "螺旋结构"],
  limit: 3,
  minScore: 75
})
```

## 输出增强

### 输出字段

- `[主题分类]`：文章所属的主题分类标签
- `[核心意象]`：文章中使用的核心隐喻
- `[匹配理由]`：概念映射方式的简要说明
- 技法列表

### 输出示例

```
=== 范文 1/3:都是为了你好 (82分) ===

[匹配理由] 家庭匹配：愧疚、亏欠；技法匹配：细节锚定、螺旋结构
[核心意象] 绳子、账本、窗户

[可学习技法]
  - 细节锚定
  - 螺旋结构
  - 金句示例："爱之名的枷锁最沉重"

[需规避问题]
  - 文风问题：说教框架出现 3 次
  - 结构问题：转折过多
```

## 维护指南

### 扩展词库

1. 在对应 JSON 文件中添加新词或新概念
2. 调用 `recommend({ rebuildIndex: true })` 重建索引
3. 或者直接删除 `output/.article-index.json` 缓存文件

### 添加新主题分类

编辑 `topic-lexicon.json`，添加新分类：

```json
"new_category": {
  "name": "新分类名称",
  "keywords": ["关键词1", "关键词2", "关键词3"],
  "weight": 1.3
}
```

### 添加新技法识别

编辑 `technique-lexicon.json`，添加新技法：

```json
"new_technique": {
  "name": "新技法名称",
  "description": "技法描述",
  "keywords": ["关键词1", "关键词2"],
  "indicators": ["句式1", "句式2"],
  "weight": 1.2
}
```
