# 文章评分方法

## 概述

本项目采用**双重评分体系**：
1. **批评者评分**（4人）：基于检查项扣分机制，0-100分
2. **读者评分**（5人）：基于阅读感受的主观评分，0-100分

最终综合评分采用**非线性惩罚机制**，确保批评者发现的问题能够合理影响最终得分。

---

## 一、批评者评分机制

### 1.1 核心参数

| 参数 | 值 | 说明 |
|------|----|------|
| `DEDUCTION_BASE` | 5 | 每单位扣分基数 |
| `REJECT_THRESHOLD` | 40 | 总分扣到40及以上，整体REJECT |
| `SEVERE_SEVERITY_MIN` | 4 | 严重倍率阈值（>=4算严重拒绝） |

### 1.2 检查结果类型

| 结果 | 说明 | 扣分计算 |
|------|------|----------|
| `PASS` | 通过 | 0分 |
| `DOUBT` | 存疑 | 倍率 x 5 分/项 |
| `REJECT` | 拒绝 | 出现次数 x 倍率 x 5 分 |

### 1.3 分项倍率与拒绝条件

#### A. 原创性审查（critic-originality）

| 项 | 倍率 | 拒绝条件 |
|----|------|----------|
| A1 从 ref/ 复制句子结构 | 5 | >=1 项发现 |
| A2 素材非来自个人经验 | 5 | >=1 项发现 |
| A3 意象/隐喻与 ref/ 功能重叠 | 3 | >=2 项发现 |
| A4 结尾句子结构与 ref/ 相似 | 5 | >=1 项发现 |

**拒绝触发**：任一严重倍率项(>=4)触发 或 总分扣分>=40

#### B. 结构与技法审查（critic-structure）

| 项 | 倍率 | 拒绝条件 |
|----|------|----------|
| B1 议论文检测 | 4 | 拒绝 |
| B2 螺旋自然度 | 4 | 拒绝 |
| B3 金句存在性 | 1 | 拒绝 |
| B4 金句质量 | 2 | 拒绝 |
| B5 隐喻一致性 | 3 | 拒绝 |
| B6 功能排比 | 2 | 拒绝 |
| B7 维度锚定 | 3 | 拒绝 |
| B8 感官场景使用 | 2 | 拒绝 |
| B9 矛盾保留 | 3 | 拒绝 |
| B10 结尾开放性 | 4 | 拒绝 |
| B11 角色检查 | 2 | 拒绝 |
| B12 认知检查 | 4 | 拒绝 |

**拒绝触发**：B1/B2/B10/B12 触发 或 总分扣分>=40

#### C. 文风与合规审查（critic-voice）

| 项 | 倍率 | 拒绝条件 |
|----|------|----------|
| C1 社群声音（"我们" vs "你"） | 4 | 拒绝 |
| C2 感叹号使用 | 1 | 拒绝 |
| C3 为读者下结论 | 4 | 拒绝 |
| C4 学术风格引用 | 2 | 拒绝 |
| C5 励志语气 | 3 | 拒绝 |
| C6 说教框架 | 3 | 拒绝 |
| C7 语言合规性（仅中文） | 1 | 拒绝 |
| C8 体裁一致性 | 3 | 拒绝 |

**拒绝触发**：C1/C3 触发 或 总分扣分>=40

#### D. AI 感审查（critic-ai）

| 项 | 倍率 | 拒绝条件 |
|----|------|----------|
| D1 突发度（Burstiness） | 3 | 拒绝 |
| D2 句式重复 | 2 | 拒绝 |
| D3 过渡脚手架 | 3 | 拒绝 |
| D4 词汇安全区概率 | 2 | 拒绝 |
| D5 情绪平坦度 | 3 | 拒绝 |
| D6 金句设计感 | 2 | 拒绝 |
| D7 举例通用性 | 3 | 拒绝 |
| D8 安全区重复使用 | 2 | 拒绝 |

**拒绝触发**：D1/D3/D5 触发 或 总分扣分>=40

### 1.4 评分计算公式

```
单项扣分 = 结果类型 x 倍率 x 单位基数

其中：
- PASS: 0
- DOUBT: 1 x 倍率 x 5
- REJECT: 出现次数 x 倍率 x 5

总分 = max(0, 100 - 总扣分)

最终判定：
- 若 任一严重倍率项(>=4)触发 REJECT -> 整体 REJECT
- 或 总分扣分 >= 40 -> 整体 REJECT
- 否则 -> PASS
```

### 1.5 评分示例

**示例 1：轻微问题**
```
检查项：
- A1: PASS (倍率5) -> 0分
- A2: DOUBT (倍率5) -> 1x5=5分
- A3: PASS (倍率3) -> 0分
- A4: PASS (倍率5) -> 0分

总分 = 100 - 5 = 95分
判定：PASS
```

**示例 2：严重问题**
```
检查项：
- B1: REJECT, 出现2次 (倍率4) -> 2x4x5 = 40分
- B2: PASS (倍率4) -> 0分
- B3: DOUBT (倍率1) -> 5分

总分 = 100 - 45 = 55分
判定：REJECT（严重倍率项触发）
```

## 二、读者评分机制

### 2.1 读者类型与评价维度

| 类别 | 风格选项 | 评价维度 |
|------|---------|----------|
| 情感类 | 感性读者、怀旧型读者、共情型读者 | 共情程度、怀旧强度、共情深度 |
| 理性类 | 怀疑论者、哲学型读者、实用主义者 | 逻辑漏洞、前提审视、实用价值 |
| 语言类 | 审美型读者、翻译耳读者、节奏型读者 | 语言质感、中文自然度、节奏感 |
| 体验类 | 普通路人、亲历者型、文化比较者 | 留存度、真实感、文化自觉 |
| 安全类 | 锐度审查者、套路督察官、权力审视者、庸俗读者、完整性审查者 | 内容锐度、套路密度、操控痕迹、注意力留存、论证完整度 |

### 2.2 评分等级

| 等级 | 分数范围 | 说明 |
|------|----------|------|
| 高 | 80-100 | 强烈共鸣，深度认可 |
| 中 | 60-79 | 基本认可，部分存疑 |
| 低 | 0-59 | 不认可或无感 |

### 2.3 读者评分输出字段

读者子代理通过 `write-reader-report` 工具写入报告，主要输出字段：

```json
{
  "article": "文章名",
  "style": "感性读者",
  "score": 85,
  "overall_evaluation": "情绪饱满，但结尾略显仓促",
  "evaluation": "共情程度：高",
  "highlights": [
    { "content": "亮点描述", "citation": "原文引用", "technique": "细节锚定" }
  ],
  "weaknesses": [
    { "content": "可改进点", "citation": "原文引用" }
  ],
  "free_response": "自由感受补充，3句话以内",
  "ai_suspicion": ["结构太工整", "举例太通用"]
}
```

其中 `metadata_highlights` 和 `metadata_weaknesses` 由工具自动编号（`RH01`, `RW01` 等）并写入 JSON 文件。

## 三、综合评分算法

### 3.1 核心逻辑

综合评分采用**非线性惩罚机制**，将批评者发现的问题作为读者评分的惩罚系数：

```
综合评分 = 读者平均分 x (最低批评得分/100)^0.7
```

### 3.2 算法详解

```
1. 计算读者平均分：
   reader_avg = 读者评分之和 / 读者数量

2. 取批评者中的最低分：
   min_critic = min(批评者1得分, 批评者2得分, ...)

3. 计算惩罚乘数：
   multiplier = (min_critic / 100) ^ 0.7
   （0.7次方曲线：温和但持续的惩罚）

4. 最终综合评分（四舍五入）：
   final_score = round(reader_avg x multiplier)
```

### 3.3 惩罚曲线说明

采用 0.7 次方的惩罚曲线特性：

| 最低批评分 | 乘数 | 说明 |
|-----------|------|------|
| 100 | 1.00 | 完美，无惩罚 |
| 95 | 0.965 | 轻微扣分，影响不大 |
| 90 | 0.928 | 轻度惩罚 |
| 85 | 0.892 | 中度惩罚 |
| 80 | 0.855 | 明显惩罚 |
| 70 | 0.777 | 显著惩罚 |
| 60 | 0.696 | 严重惩罚 |

**设计意图**：
- 无门限、平滑连续的函数，避免"刚好及格"的套利
- 高分区惩罚轻微，鼓励接近完美
- 低分区惩罚显著，确保问题文章得到应有评价
- 不使用线性惩罚，保留读者评分的主导地位

### 3.4 综合评分示例

**示例 1：优秀文章**
```
读者评分：[90, 85, 92, 88, 95]
读者平均分 = 90

批评者得分：[98, 95, 96, 99]
最低批评分 = 95

乘数 = (95/100)^0.7 -> 0.965

综合评分 = round(90 x 0.965) = 87分
```

**示例 2：有缺陷文章**
```
读者评分：[80, 75, 85, 78, 82]
读者平均分 = 80

批评者得分：[90, 75, 85, 80]
最低批评分 = 75

乘数 = (75/100)^0.7 -> 0.822

综合评分 = round(80 x 0.822) = 66分
```

**示例 3：问题文章**
```
读者评分：[70, 65, 75, 68, 72]
读者平均分 = 70

批评者得分：[65, 55, 70, 60]
最低批评分 = 55

乘数 = (55/100)^0.7 -> 0.671

综合评分 = round(70 x 0.671) = 47分
```

## 四、审校纪律与整体判定

### 4.1 单批评者判定规则

每个批评者通过 `write-critic-report` 工具独立判定：

```
if (存在严重倍率项(>=4) REJECT) OR (总扣分 >= 40):
    批评者判定 = REJECT
else:
    批评者判定 = PASS
```

### 4.2 最终判定规则（Kaltsit 层）

Kaltsit 接收 4 个批评者的判定结果后，进行整体判定：

```
REJECT 批评者数量 > 0 -> 整体 REJECT
否则 -> PASS
```

此外，Kaltsit 还会累计所有子代理（含读者）的存疑项：
- 累计存疑项 >= 2 也触发整体 REJECT

判定输出示例：
```
最终判定：不通过

批评结果：
  [PASS] 3/4
  [REJECT] 1/4

存疑项：2（B3存疑、D2存疑）
```

### 4.3 元数据评分

文章终稿的评分字段写入 `output/<文章名>.meta.json`，由 Priestess 调用 `append-metadata` 工具生成。综合评分自动从 `tmp/review-report.md` 中提取。

## 五、评分校准指南

### 5.1 批评者校准原则

- **严格一致性**：相同类型问题扣分必须一致
- **倍率适配**：问题严重度严格匹配对应倍率
- **次数统计**：REJECT 项必须统计实际出现次数
- **存疑保守**：DOUBT 应保守使用，不确定才标记

### 5.2 读者校准原则

- **评分区分度**：避免全部打90+，应有合理分布
- **维度对应**：评分应与评价维度描述一致
- **例证充分**：高分/低分都应提供具体例证
- **风格一致**：同类型读者评分基准应一致

### 5.3 异常检测

以下情况需要人工复核：
- 读者平均分与批评最低分相差 > 30
- 某批评者评分与其他批评者相差 > 20
- 同类别读者评分相差 > 25
- 综合评分与任一单项评分相差 > 25
