# essence 工具使用说明

## 概述

`essence` 是高分优秀范文工具，提供三种使用模式：
1. 按分数列出优秀文章并显示全文
2. 指定文章名获取单篇完整原文
3. 列出所有可用文章清单

与 `recommend` 工具互补使用：
- **recommend**：主题匹配优先，低 tokens 输出技法摘要
- **essence**：分数优先，输出完整原文

## 快速开始

### 模式 1：列出高分范文（默认）

```typescript
await tool.call("essence", {
  limit: 3,           // 最多显示3篇，默认3
  minScore: 80        // 最低80分，默认80
})
```

**输出示例：**
```
『 高分优秀范文 (≥80分，共 3/5 篇) 』

 排名   分数        标题                 文件
------------------------------------------------------------
   1     85    月亮不必每夜都圆      月亮不必每夜都圆.txt
   2     82    都是为了你好_v2     都是为了你好_v2.txt
   3     78    词的归处            词的归处.txt

============================================================

--- 第 1 篇：月亮不必每夜都圆 (月亮不必每夜都圆.txt) ---

...文章正文...
```

### 模式 2：获取指定文章原文

```typescript
await tool.call("essence", {
  name: "词的归处.txt"    // 指定文件名
})
```

**输出示例：**
```
『 词的归处.txt 』

# 词的归处

有一段时间，玩家之间流行一句话："这不叫福利，这是我的劳动所得。"
...完整文章正文...
```

**模糊匹配：** 文件名支持模糊匹配，输入"词的归处"或"归处"都能匹配到。

### 模式 3：列出所有文章清单

```typescript
await tool.call("essence", {
  list: true
})
```

**输出示例：**
```
『 文章清单 (共 7 篇) 』

 分数        标题                 文件名
------------------------------------------------------------
   85    月亮不必每夜都圆      月亮不必每夜都圆.txt
   82    都是为了你好_v2     都是为了你好_v2.txt
   78    词的归处            词的归处.txt
   75    在误解之后          在误解之后.txt
   72    鞭子                鞭子.txt
   70    看不见的账本        看不见的账本.txt
   68    灵魂伴侣还是身体伴侣  灵魂伴侣还是身体伴侣_v2.txt

💡 使用 essence(name="文件名") 查看完整原文
```

## 完整参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | string | 可选 | 文章文件名，支持模糊匹配。指定后忽略其他参数。 |
| `limit` | number | 3 | 最多显示篇数，0 表示全部。 |
| `minScore` | number | 80 | 最低入选分数。 |
| `list` | boolean | false | 仅列出所有文章清单，不显示内容。 |

## 与 recommend 工具配合

| 场景 | 推荐工具 |
|------|---------|
| 刚开始写作，需要学习同类主题的写作技法 | `recommend` |
| 找到感兴趣的文章，需要查看完整原文 | `essence(name="xxx")` |
| 想浏览所有已完成的文章概览 | `essence(list=true)` |
| 想参考最高分的几篇文章的整体风格 | `essence(minScore=85)` |

**典型写作流程：**

```
1. recommend("愧疚教育") → 获取 2 篇相关主题的技法摘要
2. essence(name="都是为了你好_v2.txt") → 感兴趣某篇，查看完整原文
3. 开始写作
```

## 使用示例

### 查看特定分数段的文章

```typescript
// 只看 85 分以上的顶级范文
await tool.call("essence", { minScore: 85 })
```

### 列出所有文章（不限制分数）

```typescript
// 不限制分数，列出所有文章
await tool.call("essence", { minScore: 0, limit: 0 })
```

### 从 recommend 跳转查看全文

```typescript
// 1. 先获取推荐
const rec = await tool.call("recommend", { topic: "语言异化" })

// 2. 从推荐结果中看到感兴趣的文章
// === 范文 1/2：《词的归处》(78分) ===

// 3. 获取完整原文
await tool.call("essence", { name: "词的归处" })
```

## 最佳实践

1. **先用 recommend 缩小范围**：写作初期先看技法摘要，确定方向后再看全文
2. **全文阅读不超过 2 篇**：避免被前人内容过度影响，保持原创性
3. **重点学习结构节奏**：不要关注具体句子，关注段落长度、转折位置、金句分布
4. **list 模式定期复盘**：完成 3-5 篇文章后，用 `essence(list=true)` 整体审视风格变化
