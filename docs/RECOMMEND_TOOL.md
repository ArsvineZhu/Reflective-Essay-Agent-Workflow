# recommend 工具使用说明

## 概述

`recommend` 是一个低 tokens 占用的智能范文推荐工具，根据写作主题匹配相关文章，并输出结构化的技法摘要。

**对比 essence 工具：**
- tokens 占用减少 ~85%（~500 tokens vs ~3500 tokens）
- 按主题语义匹配，而非仅分数排序
- 自动提取可学习技法和需规避问题
- 首次运行自动生成索引，增量更新

## 快速开始

### 基础调用

```typescript
// Esperanta 写作流程中调用
await tool.call("recommend", {
  topic: "愧疚教育与原生家庭"
})
```

### 完整参数

```typescript
await tool.call("recommend", {
  topic: "愧疚教育与原生家庭",      // 写作命题/主题（必填）
  limit: 3,                          // 推荐篇数，默认3
  minScore: 70,                      // 最低入选分数，默认70
  mode: "technique",                 // 输出模式：technique / full
  techniques: ["螺旋结构", "细节锚定"], // 指定技法偏好，可选
  categories: ["家庭与亲情"],         // 指定主题分类过滤，可选
  rebuildIndex: false,               // 强制重建索引，默认false
  updateLexicon: true                // 使用哈工大词林扩充词库后执行推荐，默认true
})
```

## 输出格式

### technique 模式（默认）

```
==== 范文推荐 —— 主题：愧疚教育 ====

=== 范文 1/2:《都是为了你好》(82分) ===

[匹配理由] 主题匹配 45%
[核心主题] 愧疚、教育、原生家庭、控制
[结构类型] 螺旋推进

[可学习技法]
  - 运用「细节锚定」技法
  - 以日常对话场景切入抽象命题
  - 悖论式金句："爱的名义下最残忍的控制"
  - 核心意象：绳子、账本、窗户

[需规避问题]
  - 避免说教框架过多
  - 结尾收束不要太干净

=== 范文 2/2:《鞭子》(78分) ===
...

---
共匹配 2 篇相关范文
建议：重点学习结构类型和成功意象，不要照搬具体句子或情节
```

### full 模式

full 模式额外包含文章的文件名信息和元数据摘要，便于定位。

## 索引机制

### 自动生成

首次运行工具时，会自动扫描 `output/` 目录并生成：
```
output/.article-index.json
```

索引包含每篇文章的：
- 主题关键词（从元数据 Topic 提取）
- 核心技法（从 Highlight 识别）
- 可学习点（金句 + 成功技法摘要）
- 需规避问题（从扣分项提取）
- 结构类型识别
- 文件修改时间（用于增量更新）

### 增量更新

索引基于文件修改时间增量更新。当有新文件被添加或修改时，下一次调用工具会自动重建变更部分的索引。

## 匹配算法

使用内置词库进行多维度语义匹配：

| 维度 | 说明 |
|------|------|
| 主题重叠 | 命题关键词与文章 topics/keywords 的概念映射匹配（含同义词扩展） |
| 技法互补 | 根据命题特征匹配对应技法文章 |
| 质量加权 | 分数越高权重越大，但不垄断 |
| 多样性奖励 | 避免推荐主题过于相似的文章 |

**回退机制：** 如匹配结果不足，自动降低分数阈值重试。

## 词库系统

recommend 工具内置完整的词库系统用于语义匹配：
- **停用词库**：过滤无实际语义的常用词
- **主题词库**：15 个主题分类，约 350 个核心关键词
- **技法词库**：12 种写作技法的关键词和句式指示器
- **概念映射词库**：19 个核心概念的同义词、近义词映射
- **问题模式库**：5 类常见问题的检测模式
- **结构模式库**：文章结构类型识别（如螺旋、线性等）

词库详情参见 `docs/LEXICON_GUIDE.md`。

## 与 essence 工具对比

| 特性 | recommend | essence |
|------|----------|---------|
| 排序方式 | 主题匹配优先 | 分数从高到低 |
| 输出内容 | 技法摘要 + 优缺点 | 全文 + 元数据 |
| 典型 tokens | ~450 (2篇) | ~3500 (2篇) |
| 学习重点 | 怎么写好（结构/技法） | 写过什么（内容参考） |
| 首次开销 | 索引生成 ~1s | 无 |

## Esperanta 集成

在写作流程中，`recommend` 已替代 `essence` 成为默认范文学习工具：

```
### 2. 加载参考源与范文
...
4. 调用 recommend 工具，传入写作主题，获得相关范文的技法摘要：
   - 重点学习：该主题下的成功结构、有效锚点方式、金句生成位置
   - 重点规避：该主题常见的扣分点、结构陷阱、意象干扰问题
   - 如范文不足，可补充调用 essence 工具查看高分文章作为备选
```

## 最佳实践

1. **主题词尽量具体**：用"愧疚教育 原生家庭"而非"教育"
2. **合理设置数量**：通常 2 篇足够，最多不超过 3 篇
3. **聚焦可迁移技法**：重点学习结构、节奏、意象运用
4. **注意规避项**：同类主题常犯的错误（如：愧疚主题容易陷入说教）

## 常见问题

**Q: 为什么推荐的文章分数不高？**
A: 推荐优先考虑主题相关性，高分但主题不匹配的文章不会被推荐。可降低 `minScore` 参数。

**Q: 索引文件需要提交到 Git 吗？**
A: 不需要。`.article-index.json` 是缓存文件，已在 `.gitignore` 中。

**Q: 为什么有些扣分理由显示得很简略？**
A: 为了节省 tokens，工具对长文本做了摘要处理。如需完整扣分理由，可直接读取文章元数据文件 `output/<文章名>.meta.json`。
